# NIRIKSHAK AI — Backend Service

FastAPI Backend REST API for NIRIKSHAK AI MPLADS Monitoring Platform.

## Features
- eSAKSHI Data Ingestion & Live Sync
- Data Validation (5-Suite Audit)
- Data Standardisation Pipeline (Dates, Currency, Taxonomy)
- Entity Resolution Engine (Work ID, MP, Vendor, IDA)
- Executive Dashboard APIs (`/api/v1/dashboard/overview`)
